¿Cómo recupero mis datos?
  1. Guarda o comparte un respaldo antes de borrar los datos o cambiar de celular.
  2. Conserva el archivo .json o .txt. El PDF sirve para leer; el respaldo permite restaurar.
  3. Abre esta página en el mismo navegador y entra a Importar respaldo.
  4. Elige el archivo, revisa el resumen y confirma Restaurar.

Cada navegador y teléfono guarda sus propios datos. Borrar los datos del sitio elimina los registros de ese navegador.
